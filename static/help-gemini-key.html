Get your own Gemini key

Everything in this portal is free except one button: Draft with AI in Video Narrator, which sends your recording to Google Gemini so it can write the timed script. That call is billed to you, on your Google account, with your key. This page is the whole route, from nothing to a working key, in about ten minutes.

You never need a key to use the rest of the portal. How to Use, the User Manual Builder, the voices and the video generation all cost nothing and ask for nothing. If you would rather not have a key at all, skip to Without a key at all.

Why your own key, and not one shared key

A key is a way to spend money. A shared key would mean one person's long video quietly spends another person's balance, and nobody could tell whose run was whose. So the portal gives every account its own key box, its own balance and its own list of runs. That is also why the portal asks you to sign in before it shows you anything: without an account there is nowhere to keep your key.

Your key is never shown back to you after you save it — the box shows the last four characters only — and no other account can read it, see it, or spend against it.

Part 1 — Get the key (5 minutes, free)

  1. Sign in to Google AI Studio Open aistudio.google.com/apikey and sign in with the Google account you want the usage billed to. A personal Gmail is fine. If this is a work account and the page refuses, your administrator has blocked AI Studio — use a personal account, or ask them to allow it.
  2. Accept the terms First time only. Read what you are agreeing to; it covers how Google may handle the content you send. Your screen recordings go to Google when you press Draft with AI, so this matters — see Keeping the key safe.
  3. Press “Create API key” AI Studio asks which Google Cloud project the key belongs to. If you have none, let it create one for you — the default name is fine. A “project” here is just a billing and quota bucket; it has nothing to do with the projects you register in this portal.
  4. Copy the key New keys look like AQ.… (about 53 characters); older ones like AIzaSy… (39). Both work. Copy it now. Google shows the full key once; afterwards you can only see a fragment of it or create a new one. Paste it somewhere safe for the next two minutes — your password manager, not a chat window.
At this point the key already works, on Google's free tier. That is enough to try Draft with AI on a short recording. The free tier has low rate limits and Google may use free-tier content to improve its products, so most people move to Part 2 before doing real work.

Part 2 — Put money behind it (5 minutes)

Google Gemini is not a prepaid wallet. You do not top it up with 20 dollars and watch it count down. You attach a billing account — a card — to the Cloud project the key belongs to, and Google charges you monthly for what you used. That is why Part 4 exists: the portal keeps your own running total, because Google will not hand it one.

  1. Open billing for the key's project On the same API keys page, find your key's row and use its Set up billing / Upgrade link. That takes you to the Google Cloud console with the right project already selected. (The long way round: console.cloud.google.com/billing → pick the project → Link a billing account.)
  2. Create a billing account Name it, choose your country and currency — currency cannot be changed later — and enter a card. Google may place a small temporary authorisation on the card to check it is real; it drops off. Depending on your country you may be asked for tax details.
  3. Link it to the project Confirm the billing account is attached to the project your key belongs to. If you have several projects, check you linked the right one: a key on an unbilled project stays on free-tier limits however much money sits in the other one.
  4. Set a budget alert — do not skip this Billing → Budgets & alerts → Create budget. Scope it to the project, set a monthly amount you are comfortable with (10 US dollars is plenty for ordinary narration work), and keep the default alerts at 50%, 90% and 100%. Google emails you as you cross each one.
    A budget alert warns; it does not stop spending. If you want a hard stop, keep the key on the free tier, or remove the billing link when you are done for the month.
  5. Check the API is on Keys created through AI Studio have the Generative Language API enabled already. If a call later fails with a message about the API not being enabled, open APIs & Services → Library, search Generative Language API, and press Enable.

Part 3 — Put the key into the portal

  1. Sign in to this portal With your own account. If you do not have one, the portal's owner creates it for you from Setup → People.
  2. Open Key Management In the left menu, under Portal.
  3. Paste the key into “Your Google Gemini API key” Leave Gemini model at gemini-flash-latest unless you have a reason to change it. New keys are not offered gemini-2.5-flash; if you pick a model your key cannot use, Save and test moves you to one it can. Flash is the cheap, fast model, and it watches video.
  4. Press “Save keys” The field changes to •••••••• and the last four characters. That is correct — the key is stored on the server and is never sent back to a browser again, not even to yours.
  5. Prove it works Go to Video Narrator, open or upload a short recording, and read the line under Draft with AI. With no key it says so plainly; with a key it names your model and the estimated cost and time for that video. Press Draft with AI and watch the progress. When it finishes, the log line shows what it really cost.

Part 4 — Tell the portal what you loaded

Google bills monthly and gives the portal no way to read your balance. So the portal keeps a figure you set yourself:

  • In Key Management → Money left, type the amount you are willing to spend this month — the same number you used for the budget alert in Part 2.
  • Every run subtracts its real cost from that figure.
  • When the remainder gets thin the portal says so, on this screen and on the Draft button.
This is your budget tracker, not Google's balance. It is only as honest as the number you typed, and it does not know about spending you did elsewhere with the same key. Google's own figure is in Cloud Billing → Reports, and that is the one that gets charged.

What this actually costs

Gemini charges per token. For video it counts roughly 290 tokens per second of recording, plus the prompt, plus what it writes back. On gemini-flash-latest that works out at small change:

RecordingRough cost of one draft
1 minutea few US cents
5 minutesaround ten US cents
20 minutesa few tens of US cents

The portal shows its own estimate for your video before you press anything, and the real cost afterwards — so you never have to take a table's word for it. Prices change; the authority is Google's Gemini API pricing page.

Drafting again on the same video costs again. Editing lines, choosing voices, generating the narrated MP4, subtitles and chapters are all free and unlimited: the voices come from edge-tts and the video work is done by ffmpeg on this server.

Without a key at all

If you do not want a Google key, or your organisation will not allow one, use the LLM Bridge button beside Draft with AI. It gives you the exact same prompt the portal would have sent. Run it in any model you already pay for that can watch video — Gemini in a browser, ChatGPT, Claude, an in-house model — attach your recording, and paste the JSON it returns back into the dialog. The portal reads it through the same parser and fills the same table.

Nothing leaves this server on that path, which is often the answer when the recording shows customer data.

When something goes wrong

What you seeWhat it means
“Add your own Google Gemini API key in Key Management first” Your account has no key saved. Part 3. Somebody else's key does not count — keys are per person.
API key not valid / invalid argument The key was mistyped, truncated on paste, or deleted in AI Studio. Create a fresh one and save it again.
Permission denied / API not enabled The Generative Language API is off for that Cloud project. Part 2, last step.
Quota exceeded / rate limit / 429 Free-tier limits, or too many runs in a minute. Wait, or attach billing (Part 2).
Billing account not configured The key's project has no billing account linked. Part 2, step 3 — check you linked the right project.
“the AI could not process this video” Google rejected the file. Re-export as MP4 (H.264) and keep it under an hour.
“the AI returned no usable lines” The model answered with something that was not a timed script. Press Draft again, or use the LLM Bridge.
The run is slow Google has to watch the whole recording first. A twenty-minute video takes minutes, not seconds. The progress bar is honest.

Keeping the key safe

  • Treat the key like a password. Anyone holding it can spend your money. Never paste it into a chat, a ticket, a screenshot or a shared document.
  • Never commit it. The portal stores it in data/, which is excluded from git on purpose.
  • Restrict it if you can: APIs & Services → Credentials → your key → restrict it to the Generative Language API. A leaked key then buys an attacker far less.
  • Rotate it if you suspect it leaked: create a new key, save it here, then delete the old one in AI Studio. In that order, so nothing breaks in between.
  • Watch what is on screen. Draft with AI sends the recording itself to Google. If the recording shows real customer names, emails, phone numbers or account details, record a demonstration account instead — or use the LLM Bridge and keep the file where it is.
  • Leaving? Delete the key in AI Studio and clear the box in Key Management. Removing your portal account does not cancel anything on Google's side.
